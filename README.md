# -CPU-
哈尔滨工业大学（深圳）计算机科学与技术学院2025夏计算机设计与实践实验，此处CPU的ISA为RISC-V
实现的指令总共有37个（在基础要求的24条指令的基础上多实现了13条指令）： add,sub,and,or,xor,sll,srl,sra,slt,sltu,addi,andi,ori,xori,slli,srli,srai ,slti,sltiu,lb,lbu,lh,lhu,lw,jalr,sb,sh,sw,beq,bne,blt,bltu,bge,bgeu,lui,auipc,jal
单周期CPU频率为50MHz 流水线CPU频率为100MHz
利用前递和停顿的方法解决了数据冒险，利用流水线暂停的方法解决了控制冒险.
